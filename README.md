# Платформа QDA

Настільна програма для феноменологічних якісних досліджень (macOS і Windows). Специфікація — «ТЗ_платформа_якісних_досліджень.md» і «План_етапу_1.md» у Context проєкту Claude.

## Як отримати інсталятор

**Завантажити:** https://github.com/yegorbutsykin-coder/qda-platform/releases/latest — у розділі Assets файл `.dmg` для Mac або `setup.exe` для Windows (акаунт GitHub не потрібен). Після кожної зміни GitHub сам збирає програму й додає інсталятори туди; ті самі файли є й у вкладці **Actions** → «Build installers» → «Artifacts».

## Перше відкриття на Mac

Програма ще не підписана в Apple, тому macOS її спершу блокує:

1. Відкрийте `.dmg` і перетягніть «QDA Platform» у «Програми» (Applications).
2. Запустіть її — з'явиться повідомлення, що програму не вдалося перевірити. Натисніть «Готово».
3. «Системні параметри» → «Приватність і безпека» → унизу «Усе одно відкрити» (Open Anyway) → підтвердьте паролем Mac.

Це потрібно лише один раз для кожної нової версії.
