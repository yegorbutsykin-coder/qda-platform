# Тестові транскрипти

Усі люди, місця й події **вигадані**. Файли — для перевірки додавання інтерв'ю й словника замін у різних форматах:

- `Інтерв'ю 01` — txt (UTF-8), повні позначки мовців і таймкоди; кілька абзаців однієї репліки; «Віра» як ім'я і як слово.
- `Інтерв'ю 02` — docx, мовці позначені літерами «І» і «Р», суржик.
- `Інтерв'ю 03` — txt у старому кодуванні Windows-1251, без позначок мовців.
